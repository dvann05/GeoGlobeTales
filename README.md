# GeoGlobeTales

Geographic Region Reveal Video Production System.

Aplikasi untuk membuat video edukasi sejarah dan geografi
berbasis animasi peta, narasi Bahasa Indonesia, dan Remotion.

## Target
- Video MP4
- Rasio 9:16 dan 16:9
- Animasi peta geografis
- Pewarnaan wilayah akurat
- TTS Bahasa Indonesia
- Musik dan efek suara
- Render otomatis melalui GitHub Actions
